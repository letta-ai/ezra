# Message Roles

## The Error

```
422 Unprocessable Entity: role='tool' is not allowed
```

## Why It Happens

Tool messages are auto-generated by the server during tool execution.
You can only send `user`, `system`, or `assistant` role messages.

## Fix

```python
# WRONG - tool role not allowed
messages=[{"role": "tool", "content": "result data"}]

# RIGHT - use user or system
messages=[{"role": "user", "content": "Here is the data: ..."}]
```

## Shorthand

For a single user message, use `input`:
```python
response = client.agents.messages.create(agent_id=agent.id, input="Hello!")
```

## Multiple Messages

```python
response = client.agents.messages.create(
    agent_id=agent.id,
    messages=[
        {"role": "system", "content": "Be concise."},
        {"role": "user", "content": "What is Letta?"},
    ],
)
```
